# 🤖 پارس‌ایجنت (ParsAgent) — نسخه ۱.۲.۰

**ایجنت اتوماسیون هوشمند برای ویندوز** — موس و کیبورد را کنترل و ضبط می‌کند، و صفحات وب را **در سطح کد و بدون دخالت موس/کیبورد** هدایت می‌کند. برای شبکه‌های اجتماعی (اینستاگرام، توییتر/ایکس، تلگرام، فیسبوک، لینکدین و ایرانی‌ها: **بله، روبیکا، ایتا**) ماژول بهینه‌شده دارد.

> 💡 **سریع‌ترین راه استفاده: لانچر گرافیکی** — روی `ParsAgent.bat` دابل‌کلیک کن،
> اولین بار دکمهٔ «📦 نصب پیش‌نیازها» و بعد دکمهٔ «🚀 اجرای سرور» را بزن؛
> پنل کنترل به‌صورت خودکار در مرورگر باز می‌شود: `http://127.0.0.1:8765`

---

## ✨ امکانات

| قابلیت | موتور | توضیح |
|---|---|---|
| 🖱️ کنترل موس و کیبورد | `SystemController` (PyAutoGUI) | کلیک، درگ، اسکرول، تایپ، هاتکی — با تاخیر و لرزش انسانی |
| ⏺️ ضبط و بازپخش ورودی | `InputRecorder` (pynput) | کل حرکات/کلیک‌ها/کلیدها را ضبط می‌کند → ماکرو JSON → بازپخش با هر سرعت |
| 🌐 اتوماسیون وب | `BrowserEngine` (Playwright) | کرومیوم را در سطح DOM هدایت می‌کند؛ **بدون شبیه‌سازی ورودی** — حین کار می‌توانید با PC کار کنید |
| 🛡️ لانچر مقاوم | `FALLBACK_CHANNELS` | اول Edge خود ویندوز، بعد Chrome، بعد کرومیوم باندل — **حتی زیر تحریم و بدون دانلود** کار می‌کند |
| 👤 پروفایل به‌ازای هر پلتفرم | `data/profiles/<platform>` | لاگین هر شبکه اجتماعی در پروفایل جدا ذخیره می‌شود؛ بین اینستاگرام/تلگرام/بله تداخل نمی‌کند |
| 🥷 ضد شناسایی v2 | `core/stealth.py` | سه لایه: پرچم‌های ضد اتوماسیون + اسکریپت ماژولار (webdriver، chrome.runtime، Canvas/Audio/WebGL، پلاگین‌ها، Permissions) + رفتار انسانی — با **اثر انگشت پایدار برای هر پروفایل** |
| 🔑 ورود خودکار | پنل ← پلتفرم‌ها | نام کاربری/رمز/شماره را در تنظیمات ذخیره کن؛ «⚡ ورود خودکار» فرم را پر می‌کند، کد ۲FA (TOTP) را خودش می‌سازد و سرراه کپچا را حل می‌کند |
| 🤖 حل کپچا | `core/captcha.py` | سازگار با 2Captcha/RuCaptcha — reCAPTCHA v2/v3، hCaptcha، Turnstile، FunCaptcha و کپچای تصویری |
| 🔐 مخزن حساب‌ها | `data/credentials.json` | رمزها فقط روی سیستم خودت — پنل هرگز رمز را به مرورگر نمی‌فرستد |
| 🧩 ماژول پلتفرم‌ها | `platforms/` | ورود، پست، دایرکت، فالو، لایک، کامنت برای ۸ شبکه اجتماعی |
| ⏰ زمان‌بند | `Scheduler` | اجرای دوره‌ای (`--every 30m`) یا روزانه (`--at 09:30`) تسک‌ها |
| 🛰️ کنترل از راه دور | `GatewayClient` | اتصال WebSocket به پنل وب؛ دریافت دستور، ارسال تله‌متری و لاگ |
| 🔔 اعلان ویندوز | `notify()` | Toast برای پایان تسک/خطاها (plyer) |
| 🖥️ پنل وب محلی | `server.py` + `web/` | کنترل همهٔ قابلیت‌ها از مرورگر (FastAPI + WebSocket) — فقط روی 127.0.0.1 |
| 🚀 لانچر گرافیکی | `launcher.py` | نصب پیش‌نیازها، اجرا/توقف سرور و باز شدن خودکار پنل — بدون ترمینال |

## 🚀 نصب (ویندوز)

### 🖥️ راه اول: لانچر گرافیکی (پیشنهادی)

```bat
:: 1) پایتون 3.10+ را نصب کنید (python.org — تیک Add to PATH)

:: 2) دابل‌کلیک روی ParsAgent.bat   (یا: python launcher.py)

:: 3) در لانچر: اولین بار «نصب پیش‌نیازها» → بعد «اجرای سرور»
::    پنل خودکار در مرورگر باز می‌شود:  http://127.0.0.1:8765
```

از پنل می‌توانی: باز/بستن مرورگر ۸ پلتفرم + اجرای اکشن‌ها، **ورود خودکار با
حساب ذخیره‌شده (+ حل کپچا و کد ۲FA)**، اجرا/ساخت/ویرایش وظایف JSON، ضبط و
بازپخش ماکرو (یا با F9/F10)، کنترل موس/کیبورد روی اسکرین‌شات زنده، دستور
سیستمی، اعلان، خاموشی زمان‌بندی‌شده، لاگ زنده، ویرایش config.json و
**تنظیمات ضد شناسایی با تست اثر انگشت** — همه با چند کلیک.

### ⌨️ راه دوم: خط فرمان (CLI)

```bat
:: 1) پایتون 3.10+ را نصب کنید (python.org)

:: 2) نصب وابستگی‌ها
pip install -r requirements.txt

:: 3) مرورگر — روی ویندوز ۱۰/۱۱ معمولاً هیچ کاری لازم نیست!
::    لانچر مقاوم اول Edge خود ویندوز را استفاده می‌کند (بعد Chrome، بعد کرومیوم).
::    فقط اگر هیچ‌کدام نبود، از آینه نصب کنید (بدون فیلترشکن):
install_browsers.bat
::    یا معادل CLI:
python main.py install

:: 4) اجرای راهنما
python main.py --help

:: 5) اجرای سرور پنل بدون لانچر
python server.py
```

### 🛡️ نصب مرورگر در ایران — رفع خطای 403 (AccessDenied)

اگر دستور `playwright install chromium` با خطای `403 AccessDenied`
(تحریم CDN رسمی `cdn.playwright.dev`) مواجه شد، سه راه دارید —
**راه ۱ تقریباً همیشه کافی است:**

| # | راه‌حل | توضیح |
|---|---|---|
| ۱ | **هیچ دانلودی لازم نیست** | لانچر پارس‌ایجنت اول **Edge ویندوز** (`channel="msedge"`) را امتحان می‌کند؛ Edge روی Win10/11 همیشه نصب است. بعد Chrome، بعد کرومیوم باندل. فقط `python main.py demo` را اجرا کنید |
| ۲ | **آینه چینی npmmirror** | `install_browsers.bat` یا `python main.py install` — متغیر `PLAYWRIGHT_DOWNLOAD_HOST` را روی `cdn.npmmirror.com` می‌گذارد که در ایران بدون فیلترشکن در دسترس است |
| ۳ | **پروکسی/فیلترشکن** | `set HTTPS_PROXY=http://127.0.0.1:PORT` و بعد `python -m playwright install chromium` |

نکته: برای اجبار یک کانال خاص در `config.json` مقدار `browser.channel`
را ست کنید (مثلاً `"msedge"`)؛ پیش‌فرض ترتیب `channel_fallbacks` است.
اگر یک پروفایل را با موتورهای مختلف (Edge/کرومیوم) باز و بسته کردید و
مرورگر crash کرد، پوشه همان پروفایل را در `data/profiles/` حذف کنید.

## 🎮 استفاده سریع

```bat
:: فهرست پلتفرم‌ها
python main.py platforms

:: (در صورت نیاز) نصب کرومیوم از آینه — بدون فیلترشکن
python main.py install

:: ورود اول به تلگرام (کد را در همین کنسول تایپ کنید؛ سشن ذخیره می‌شود)
python main.py login telegram

:: اجرای یک تسک از فایل نمونه
python main.py run tasks/examples.json -t post_instagram_photo

:: تست بدون عملیات واقعی
python main.py run tasks/examples.json -t morning_routine --dry

:: ضبط ماکرو: F9 پایان، F10 لغو
python main.py record -o macros/tik.json

:: بازپخش ماکرو با سرعت ×۱.۵ و ۳ بار تکرار
python main.py play macros/tik.json -s 1.5 --loop 3

:: زمان‌بندی: هر ۳۰ دقیقه / هر روز ساعت ۹:۳۰
python main.py schedule tasks/examples.json -t telegram_daily_message --every 30m
python main.py schedule tasks/examples.json -t morning_routine --at 09:30

:: اتصال به پنل کنترل وب
python main.py gateway
```

## 🥷 نکات ضدشناسایی (مهم برای شبکه‌های اجتماعی)

1. **پروفایل ماندگار** — هر پلتفرم پروفایل مستقل خودش را دارد (`data/profiles/<platform>`)؛ لاگین شما بین اجراها حفظ می‌شود و لاگین‌های مکرر — که عامل اصلی بلاک شدن هستند — حذف می‌شوند.
2. **موتور ضد شناسایی v2** — از «تنظیمات ← 🛡️ ضد شناسایی بات» فعال/تنظیم می‌شود. سه سطح (پایه/استاندارد/حداکثر) و ۱۰ ماژول مستقل: حذف `navigator.webdriver` (همراه `--disable-blink-features=AutomationControlled`)، اشیای `chrome.runtime/app`، Permissions سازگار، پلاگین‌های PDF واقعی، زبان/پلتفرم، مشخصات سخت‌افزار، **نویز Canvas و AudioContext**، ماسک WebGL (رندرر ANGLE واقع‌نما) و محافظ WebRTC (با پروکسی خودکار روشن می‌شود). نویز هر پروفایل با seed ثابت ساخته می‌شود تا اثر انگشت بین اجراها **پایدار** بماند. با «🧪 تست سریع اثر انگشت» ۷ نشانهٔ اتوماسیون را در همان پروفایل چک کن و با «🌍 سایت تست بات» آزمون واقعی (bot.sannysoft.com) ببین.
3. **تاخیر انسانی** — `human.enabled=true` تایپ و کلیک‌ها را با ریتم تصادفی انجام می‌دهد.
4. **پروکسی** — در `config.json → browser.proxy` پروکسی (ترجیحاً رزیدنشوال) تنظیم کنید؛ IP ثابت دیتاسنتری = ریسک بالای بلاک. با پروکسی، محافظ WebRTC خودکار فعال می‌شود تا IP واقعی لو نرود.
5. **حجم معقول** — از `broadcast` بله و لایک انبوه پرهیز کنید؛ نرخ ارسال را محافظه‌کارانه نگه دارید.
6. **سشن قابل حمل** — `export_session` کوکی‌ها را جدا از پروفایل ذخیره می‌کند تا در کروم‌های دیگر بارگذاری شود.

## 🔑 ورود خودکار و حل کپچا

1. در پنل به «تنظیمات ← 🔑 حساب‌ها و ورود خودکار» برو؛ برای هر پلتفرم نام
   کاربری/ایمیل/شماره + رمز (و برای اینستاگرام/توییتر/فیسبوک/لینکدین اختیاری:
   کلید TOTP دو مرحله‌ای) را ذخیره کن.
2. در تب پلتفرم‌ها «⚡ ورود خودکار» را بزن — مرورگر همان پروفایل باز می‌شود،
   فرم پر و ارسال می‌شود، اگر کپچا بود حل و تزریق می‌شود (اگر سرویس کپچا
   فعال باشد) و اگر 2FA با کلید TOTP ذخیره کرده باشی، کد را هم خودش می‌سازد.
3. برای تلگرام/بله/روبیکا/ایتا شماره پر می‌شود و کد SMS را در همان پنجرهٔ
   باز وارد می‌کنی (پیامک به گوشی خودت می‌آید؛ پروفایل ماندگار است).
4. حل کپچا: کلید API را از 2captcha.com (یا RuCaptcha) بگیر و در همان کارت
   تنظیمات بچسبان — پشتیبانی: reCAPTCHA v2/v3، hCaptcha، Cloudflare
   Turnstile، FunCaptcha/Arkose و کپچای تصویری (سایت‌های ایرانی).
5. امنیت: رمزها فقط در `data/credentials.json` روی سیستم خودت ذخیره
   می‌شوند؛ پنل رمز را هرگز به مرورگر برنمی‌گرداند (فقط «ذخیره شده ✓»).

## 🛰️ کنترل از راه دور

`GatewayClient` با پروتکل JSON-over-WebSocket به هر پنل سازگار وصل می‌شود:

```
panel → agent :  {"type":"command","cmd":"run_task","task":{...}}
agent → panel :  {"type":"log","line":"..."} ، {"type":"telemetry","cpu":12.5,...}
```

آدرس را در `config.json → gateway.url` تنظیم و `python main.py gateway` را اجرا کنید.

## ⚠️ سلب مسئولیت

این ابزار برای **اتوماسیون قانونی حساب‌های شخصی** (زمان‌بندی محتوا، پاسخ‌دهی، مدیریت پیام‌ها و…) ساخته شده است. خودکارسازی ممکن است با شرایط استفاده (ToS) برخی پلتفرم‌ها در تعارض باشد؛ مسئولیت رعایت قوانین هر سرویس و پیامدهای احتمالی (محدودیت/مسدودی حساب) بر عهده کاربر است. اعتبارنامه‌ها را فقط در `config.json` و `data/credentials.json` محلی خود نگه دارید و آن‌ها را کامیت نکنید.

## 🧪 عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| `playwright not found` / خطای 403 در دانلود | هیچ کاری نکنید — لانچر اول Edge/Chrome نصب‌شده را استفاده می‌کند؛ یا `install_browsers.bat` / `python main.py install` (آینه، بدون فیلترشکن) |
| crash مرورگر بعد از تعویض موتور روی یک پروفایل | پوشه همان پروفایل را در `data/profiles/` حذف کنید (ناسازگاری نسخه پروفایل Edge/کرومیوم) |
| سلکتوری کار نمی‌کند | پلتفرم DOM را عوض کرده؛ آرایه سلکتورها را با DevTools به‌روز کنید (برای «ورود خودکار» هم `LOGIN_SELECTORS` در `platforms/base.py`) |
| «ورود خودکار» فیلد را پیدا نمی‌کند | سایت صفحهٔ ورود را عوض کرده — `LOGIN_SELECTORS` را به‌روز کنید یا اول مرورگر را دستی باز کن و لاگین کن (پروفایل ماندگار است) |
| موس هنگام اجرای دسکتاپ «گیر» کرد | نشانگر را به **گوشه بالا-چپ** ببرید (failsafe فعال است) |
| فارسی تایپ نمی‌شود در `type_text` | برای متن فارسی از `BrowserEngine.type` (وب) استفاده کنید؛ PyAutoGUI فقط لایوت انگلیسی را مستقیم می‌زند و کلیدها را با کد مجازی ارسال می‌کند |
